# Work data, permissions and your administrator

**Allow 3 minutes.** Grounding means using source material to help form an answer.

## What can Copilot use?

With the paid work licence, Microsoft Graph provides context such as documents, mail, chats and meetings. Work IQ and semantic indexing support broader work grounding. Copilot respects the access your account already has.

Copilot Chat outside Outlook mainly uses the web and material you explicitly provide, plus supported app context. In supported Outlook experiences, Chat can use additional mailbox and related content without the add-on. A blanket rule that “included Chat can never see work data” is out of date.

> **Important:** A permission check is not a quality check. A file you can open can still be old, incorrect or shared too widely.

## Ask IT for a small pilot

An authorised administrator can use **Microsoft 365 admin centre → Billing → Licenses → Microsoft Copilot** to assign licences. **Users → Active Users** shows assignments. Names may still include Microsoft 365 during the transition.

Before expanding use, ask IT to check:

- Which people and tasks need the add-on.
- Whether SharePoint and OneDrive access is appropriate.
- Which web-search and data controls the organisation approves.
- Whether the needed app features are enabled and available.

## Try it: 1 minute

Write an IT request: “I want to practise ___ using ___. My label is ___. Please confirm the licence, allowed data and app access.” Do not request wider file permissions just to make a prompt work.

**Done when:** you can distinguish access, source quality and licence availability.
