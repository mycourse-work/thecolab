# Word: make a first draft

Allow 4 minutes. Use an empty practice document and invented notes.

## Find the entry point

Open Word with your approved account. In Microsoft's current drafting instructions, open **Copilot in the bottom-right corner**, describe the draft, then select **Generate**. If available, typing **/** lets you choose a source file. Some versions show Copilot on the ribbon instead.

Access depends on the licence, app version and organisation settings. If your screen differs, use [Microsoft's current Word instructions](https://support.microsoft.com/en-gb/word/copilot/draft-and-add-content-with-copilot-in-word) or ask IT.

## Give it a small source

```text
Draft a one-page office visitor checklist from these invented notes:
Visitors check in at reception.
The host meets them there.
Visitors wear the pass provided by reception.
The host returns the pass when the visit ends.
Use a heading and four checklist items in NZ English.
Add an 'Items to confirm' section for any missing detail.
Do not invent emergency instructions or legal requirements.
```

Read the draft before you keep it. Check that the host still returns the pass, rather than reception. Keep only the steps that the source supports.

## Try it: 2 minutes

Create a draft and ask for shorter checklist items. Compare the responsibilities with the notes. Do not publish this as your real visitor policy.

Chat route: paste the same invented notes into an approved Copilot Chat session. Ask for the checklist, then manually copy your checked draft to Word. If you lack an approved account, write the checklist yourself.

Done when: your checklist has the supplied steps and clearly marked gaps.
