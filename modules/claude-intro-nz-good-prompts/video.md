## Text summary

A useful prompt states the task, audience, context, source facts, output format and limits. Examples show the structure you want. Follow-up messages improve a draft while you keep checking it against the source.

## By the end of this module
- Give relevant context and a clear task.
- Use an example and mark missing information.
- Revise the result and check the facts.
