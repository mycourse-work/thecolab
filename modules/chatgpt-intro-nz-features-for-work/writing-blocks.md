# Revise a draft with writing blocks or in chat

Allow 3 minutes, including the practice below.

## Keep revisions close to the source

ChatGPT may put draft text in a writing block within its response. When the actions are available, you can edit the text, copy it, or ask ChatGPT to revise a selected part or the whole draft. Available actions vary by plan, device, model, workspace settings and rollout.

Use this invented reception procedure:

```text
When a parcel arrives, check the label. Put the parcel on the
reception shelf. Tell the intended staff member it has arrived.
Do not open parcels addressed to someone else. If the label is
unclear, ask the office manager what to do.
```

Ask ChatGPT for a draft you can revise directly in the conversation:

```text
Make this supplied reception procedure easier to scan.
Use a title and numbered steps. Keep all five original instructions,
including leaving other people's parcels unopened.
Do not add a security policy. Keep this as a draft for review.
```

## Make one change, then check again

If a writing block appears and supports editing, edit one sentence or ask ChatGPT to revise the relevant text. For example: "Shorten the opening; keep all instructions." Check the whole draft afterwards.

If those controls are unavailable, ask for the same revision in chat. Compare the response with the original notes. The exercise works without a separate editing control.

A useful revision preserves checking the label, using the shelf, notifying the recipient, leaving parcels unopened, and escalating an unclear label. Any extra rule needs approval.

## Keep the approved version in your normal system

A clear draft still needs the reception owner's review. Once approved, store it in your organisation's normal document system with an owner and review date.

Try it: Make one sentence clearer. Check that all five original instructions survive. Keep the exercise fictional.
