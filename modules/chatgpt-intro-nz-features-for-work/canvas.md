# Revise a draft with canvas

**Allow 3 minutes, including any practice below.**

## Focus on a document

Canvas is ChatGPT’s workspace for writing and editing alongside a conversation. It can help when you want to revise a draft in sections. Availability depends on the tools your account shows.

Use only this invented procedure:

```text
When a parcel arrives, check the label. Put the parcel on the
reception shelf. Tell the intended staff member it has arrived.
Do not open parcels addressed to someone else. If the label is
unclear, ask the office manager what to do.
```

If canvas is offered in your account, ask ChatGPT to open this practice draft in canvas. Then ask for this change:

```text
Make this supplied reception procedure easier to scan.
Use a title and numbered steps. Keep the instruction not to
open another person's parcel. Do not add a security policy.
```

Where available, select the part you want to revise and request a specific change. Review the whole document afterwards.

## Use the same review with a normal chat

If canvas is missing, paste the procedure into a regular chat. Ask for the same revision. Compare the answer with the original five instructions.

A useful revision preserves: checking the label, using the shelf, notifying the recipient, leaving parcels unopened, and escalating an unclear label. Extra rules need someone to approve them.

## Keep the approved version in your normal system

A polished draft is still a draft. Check it with the person responsible for reception. Once approved, store it in your organisation’s normal document system with an owner and review date.

**Try it:** Make one section clearer. Check that none of the five supplied instructions disappeared. Do not use a staff or customer record as your canvas practice.
