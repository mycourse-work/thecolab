# Create a Project for repeat work

Allow 4 minutes.

A Project groups related chats, instructions and reference material. Free accounts can create up to five Projects. Team and Enterprise accounts can share Projects within the organisation where an admin allows it.

## Set up a practice Project

1. Open **Projects** in the sidebar, or visit [claude.ai/projects](https://claude.ai/projects).
2. Select **+ New Project**. Name it "Practice office emails".
3. Select **Set project instructions**, add the text below, then save.

```text
Draft for an invented NZ office. Use NZ English and short sentences.
Use only the supplied facts. Flag missing dates and owners.
Keep all work as a draft for a person to review.
Do not provide legal or tax advice.
```

Put reusable reference facts in the Project's knowledge area. The Project's name and description are not instructions Claude can read.

## Try it: reuse the instructions

Start a chat inside the Project. Ask for a reminder using the invented Hamilton example. Check whether the draft follows the Project instructions. Then start a second chat with a different invented reminder.

> **Important:** Project instructions and knowledge provide reusable context. Do not assume every earlier chat becomes a source for every new chat. Put required facts in the knowledge area or the current prompt.

Check visibility before adding material. Keep this practice Project private. An organisation's sharing options are not a reason to upload confidential material without approval.
