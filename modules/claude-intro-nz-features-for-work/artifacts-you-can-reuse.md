# Make and revise a simple Artifact

Allow 4 minutes.

An Artifact is a separate piece of output beside a Claude conversation. You can revisit and revise it. Chat-created Artifacts are available on Free, Pro, Max, Team and Enterprise. The Design, Slides and Docs templates are paid features in beta.

## Check the capability

For a personal account, open **Settings > Capabilities** and check **Cloud code execution and file creation**. It must be on to use Artifacts. Turn it on only where your employer permits it. On an organisation account, an owner manages the capability in **Organization settings > Capabilities**.

## Try it: a reusable checklist

Use this prompt in an ordinary practice chat:

```text
Create a simple Markdown artifact for an invented Wellington HR team:
a new starter office checklist with 16 short items.
Use sections for before arrival, first morning, and first week.
Each item needs an owner placeholder and a completion checkbox.
Do not include personal details or employment advice.
Keep it a draft for the office manager to review.
```

Check the checklist. Ask Claude to move first-week items into a separate section and replace any invented staff name with "[owner]". Find the result again in the **Artifacts** sidebar tab.

## Review before reuse or sharing

Compare the final checklist with your organisation's process. Keep the exercise private. Before sharing a real Artifact, inspect its contents, who can open the link, and your account's sharing controls.

If the capability is unavailable, ask for the checklist in the chat and copy the reviewed text into your own notes. You can still practise the same task.
