# Bring the features into one office workflow

Allow 3 minutes.

Use each feature for a clear purpose. A Project holds reusable instructions and approved references. A chat carries today's request. A file supplies evidence. An Artifact holds a separate output you can revise.

## An invented Wellington office workflow

| Step | Your action |
| --- | --- |
| Prepare | Read the practice notes and remove private information. |
| Place | Use a private practice Project with office writing instructions. |
| Ask | Request a checklist from the supplied notes. |
| Check | Trace every required step back to the notes. |
| Finish | Have the office manager approve the final document. |

Keep a record of the source version and reviewer in your approved system. Give the reviewer the source alongside the draft.

## Where to go next

Claude Code supports coding work. Claude Cowork covers tasks that can use files and tools. Those workflows need extra skills and permission checks. This course does not require either product. Their interfaces are changing; read the official guides before a later trial.

## Quick practice

Choose the feature you would use for each item: a recurring writing rule, a source document, and a reusable checklist. Explain your choices to a colleague or write them in your notes.

Before the quiz, explain how you would check the checklist against its source.
