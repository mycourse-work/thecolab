# Improve one thing at a time

**Allow 4 minutes, including any practice below.**

## Use a short follow-up

You do not need to write a perfect prompt on the first attempt. Read the answer, identify a specific problem, and ask for one change.

| Problem | Useful follow-up |
| --- | --- |
| The message is too long | Cut it to 80 words. Keep every supplied fact. |
| The tone is too formal | Use everyday office language and shorter sentences. |
| It invented a detail | Remove the unsupported detail. List what is still unknown. |
| It mixed facts and advice | Put supplied facts and suggestions in separate lists. |
| The output is hard to review | Put each action on its own row. |

## Review the revised version

An edit can introduce a new error. Compare the revised answer with the original source, not just with the previous answer.

For the builder’s email, this follow-up is clear:

```text
Make the email warmer. Keep the request for two visit times.
Do not add a price, booking confirmation, or start date.
Show the email and a separate list of facts that need confirmation.
```

## Ask for a check, then do your own

You can ask ChatGPT to list assumptions or point to supporting lines. Treat that as an aid to review. Its own assurance is not independent evidence.

Use this personal review note:

```text
Task:
Source facts:
Change requested:
What I checked:
What still needs a person to confirm:
```

**Try it:** Take one draft from this module. Make one change. Check that its facts survived. Save the useful prompt and your review note in your approved notes.

Your goal is a repeatable routine: supply safe facts, ask clearly, revise, and check. In the next module, you will use ChatGPT’s work features to support that routine.
